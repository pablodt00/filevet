# filevet

> **Not usable yet.** This release only reserves the name. There is no functionality to install.

filevet will be a self-hosted, open-source scanner that checks the files finance teams receive for security risks before they are opened or ingested. See [docs/SCOPE.md](https://github.com/pablodt00/filevet/blob/master/docs/SCOPE.md) for what it will and will not do.
